# Fusion Console · A 版总规格（MASTER SPEC）

> 本文件是 A 版融合的唯一构建依据（「提示词写满写圆」）：目的、形式、设计系统、六个视图的保留清单、双语字典范围、数据契约、状态规范、验收标准，全部写死在此。构建者（人或分身）不得自行增删视图要素；与本文件冲突的实现一律以本文件为准。B 版（方向 B：原风格拼贴）自本版起废止，仅作数据与资产来源保留在仓库中。

## 0. 目的、形式、用途（写这个是干吗的）

- **目的**：把使用者分散在五个项目里的五条信息流——①全球行情与自选股、②一个 Solana 纸面交易实验的实时战况、③一条 18 年定投回测的结论、④AI 安全领域的每日情报、⑤提示词可视化工具——汇成**一台个人情报控制台**：打开一个页面，一眼知道「现在什么值得我注意」，需要深究时在同一个界面里下钻到任一领域，不再于五个风格迥异、语言不通的页面之间跳转。
- **形式**：单页应用（SPA）。一副外壳（顶栏 + 左侧导航 + 内容区），六个视图（总览/行情/实验室/赛跑/蜘蛛/安全）在壳内切换；**一套设计系统**（同一套颜色、字体、圆角、间距、动效）贯穿全站；**中英双语**一键切换并记忆；所有视图吃同一组后端接口，数字口径全站一致（同一数据只许有一个来源）。
- **做什么用**：常开在电视/大屏/桌面上作日常监控与决策支持：晨起看总览（昨夜全球市场、实验盈亏、安全要闻），盘中看行情，闲暇看实验与赛跑，安全情报按日消化。它不是五个项目的陈列柜，而是一个人的注意力中枢。

## 2. 设计系统（一套风格，所有视图共用）

- **底色**：深空 `#07090f`；面板 `rgba(17,22,34,.72)` 玻璃拟态 + 1px 边框 `#1e2740`；圆角 16px（大卡）/10px（小件）；阴影 `0 10px 30px rgba(0,0,0,.45)`。
- **模块强调色**（身份色，只作点缀不作底色）：行情 `#4fd6ff`、实验室 `#ffd23f`、赛跑 `#e8b866`、蜘蛛 `#f34a87`、安全 `#ff4d5e`、总览/品牌 `#8b7cf6`。
- **涨跌色**：涨 `#2bd97c`、跌 `#ff5c5c`（中英两种语言下不变；不做红涨绿跌切换）。
- **字体**：中文 PingFang SC / Microsoft YaHei / Noto Sans CJK；英文与数字 system-ui + tabular-nums；大数字字重 700、字距收紧。
- **布局**：顶栏 56px（品牌、时钟、市场状态、五模块状态点、语言切换）；左导航 208px（图标+双语名+一行关键数）；内容区 max-width 1560px、24px 间距；≥1920px 时 KPI 字号放大一档（电视可读性）。
- **动效**：视图切换 160ms 淡入上浮；数字变化时 300ms 滚动；骨架屏闪烁代替白屏；所有动画可被 `prefers-reduced-motion` 关闭。
- **状态规范（全站统一）**：加载=骨架屏；空数据=虚线框 + 双语「暂无数据」；接口失败=面板右上角红点 + 「数据源不可达」+ 自动重试（30s）；离线模块不许让整页报错。

## 3. 六个视图（信息架构与要素，逐项写死）

### 3.1 总览 Overview（默认视图，控制台的「一眼」）
- KPI 条（6 块）：上证指数、深证成指、Degen 余额（附净值与今日胜负）、赛跑组合终值（附收益率）、今日安全精选篇数（附最新日期）、蜘蛛状态（在线/会话）。数据只来自 `/api/fusion/status`。
- **融合信息流**（本版灵魂）：三源合流的时间线——财经快讯（FinSight news）、安全精选 Top（Hub）、Degen 决策日志（state.logs）——按时间倒序、带来源色点与双语来源标签，来自 `/api/fusion/feed`；点击外链原页。
- 五模块预览卡（2 大 3 小）：行情卡=迷你指数列；实验卡=净值小曲线 + 战绩；赛跑卡=终值大数 + 六单投排行；安全卡=今日 Top3 标题；蜘蛛卡=状态 + 入口。各卡右上角「进入 →」跳对应视图。
- 页脚：数据更新时间、免责一句（双语）。

### 3.2 行情 Markets
- 指数带：`/api/finance/indices` 四大指数 + `/api/finance/global` 全球（美股/恒生/日经/欧股/加密）横向滚动条。
- 主区左：自选股表（`/api/finance/watchlist` + `/api/finance/quotes` 批量行情：名称/现价/涨跌幅/今开/高/低），点击行切换右侧个股。
- 主区右：个股面板——K 线 Canvas（`/api/finance/kline`，含 MA5/20/60、量柱）、技术摘要（`/api/finance/analyze` 的关键字段平铺）、筹码状态（`/api/finance/cyq`，未建环境时显示双语说明而非报错）。
- 底部双栏：板块榜（`/api/finance/sectors` 概念/行业切换）+ 财经快讯（`/api/finance/news`）。
- 右侧抽屉：早间选股（`/api/finance/picks` 前 6，含评分与理由）。

### 3.3 实验室 Degen Lab（数据直读上游 state.json，前端每 20s 刷新）
- 头部 KPI：余额、净值（权益曲线末值）、已实现战绩（胜/负/胜率）、当前持仓数。
- 净值曲线 Canvas（equity 全序列）。
- 机器人墙：8 个 agent 卡（名字、角色双语、状态点、其负责的持仓/战绩摘要——按 state.agents 与交易记录前端归因，归因不出时只显示角色与状态，不许编造数字）。
- 交易表双页签：持仓中（token/入场价/现值/浮盈）/ 已平仓（token/盈亏/结果）。
- 否决蛛网 Canvas：按 finals 的 veto keys 统计绘制蛛网 + Top 键列表（保留原项目的标志性可视化）。
- 决策日志：state.logs 滚动列表（时间倒序）。
- 全部文案中英双语；数字与代币名保持原文。

### 3.4 赛跑 Race
- 舞台区：iframe 嵌入现有 `/modules/race/index.html`（V3 全片本体不改），外壳提供统一标题条与关键数字条（终值/IRR/回撤/等分，取 `/api/fusion/status.race`）。
- 舞台下：六单投终值排行条（引擎 finals）+ 口径说明（双语，含「数字取引擎、与原视频印刷值差异见模块 README」）。

### 3.5 蜘蛛 Spider
- 舞台区：iframe 嵌入 `http://<同主机>:4317/`（蜘蛛本体不改）。
- 侧栏：服务状态（探 `/status`，经主干状态接口转述避免跨域误判）、11 个 MCP 工具清单（双语名+一句话用途）、「如何让 Agent 接入」三步（指向教程第 10 节与 .mcp.json）。

### 3.6 安全 Safety
- 日期导航（最新/前一天/后一天/回到最新），逻辑同现有阅读页（向 Hub 仓探最近 12 天）。
- 日报区：当日日报 MD 渲染（四栏目结构保留）。
- 精选区：30 篇卡片：主标题随语言切换（中文 titleZh / 英文 title）、一句话、venue/日期/主题 chips、作者、原文/站内双链。
- 页脚署名：数据来源 AISafetyHot-Hub · CC BY-NC 4.0（双语）。

## 4. 双语规范

- 语言状态存 `localStorage.fusion_lang`（`zh` 默认 / `en`），顶栏一键切换，全站即时重渲染（不刷新页面）。
- 字典机制：核心字典在 `i18n.js`；每个视图文件用 `registerI18n('<view>', {zh:{...}, en:{...}})` 注册自己的词条，视图内只许用 `t('view.key')` 取文案，**模板里不许写死中文或英文**（数据原文除外：股票名、代币名、论文标题按第 3 节规则处理）。
- 数字/日期格式随语言：`zh` 用 `zh-CN`、`en` 用 `en-US` 的 Intl 格式化；百分比、货币符号位置随之。
- 指数名称提供双语映射（上证指数↔SSE Composite 等 9 个主要指数 + BTC）。

## 5. 数据契约（后端，只许加不许改现有接口）

- 沿用：`/api/finance/*` 全部、`/api/fusion/status`、`/api/fusion/digest`。
- 新增 `GET /api/fusion/feed?limit=30`：返回 `{ok, items:[{ts, source:'finance'|'safety'|'degen', title, desc, url}]}`。来源：财经=`_news_global_cache_get()`；安全=当日精选 Top5（ts=当日 08:00 +08:00）；实验=上游 state.logs 末 10 条（ts 取其时间字段，无则用抓取时刻）。排序：各源内部按 ts 倒序、三源轮转交织输出（财经快讯的时间戳是同批抓取时刻，全局直排会被单一来源刷屏；交织保证三源同屏，实测 12 条为 4/4/4）。任一源失败时其余照常返回，失败源在 `degraded` 数组里报名字。
- 静态托管：`app/` 目录由现有静态规则直供；根路由 `/` 改指 `app/index.html`（FinSight 仍在 `/finance`，B 版门户文件保留但不再是根）。
- 跨域/混合内容：蜘蛛与主干同机不同端口，iframe 地址一律用「当前页面 hostname + :4317」拼装，禁止写死 localhost。

## 6. 验收标准（逐条可核对）

1. `/` 打开即控制台总览，六视图可切换且地址 hash 同步（#overview/#markets/#degen/#race/#spider/#safety），刷新后停留在当前视图。
2. 六视图全部呈现真实数据（以审计时的实时值为准），无任何写死的假数字；任一数据源断开时对应面板按状态规范降级、整页不崩。
3. 中英切换：任意视图点切换，所有外壳与视图文案即时变语言，刷新后保持；模板内无写死文案（抽查源码 grep 中文字符串只应出现在字典与数据处理处）。
4. 统一风格：六视图共用同一 CSS 变量与组件类（卡片/表格/页签/骨架），无视图私自引入外部字体或 CDN。
5. 保留清单第 1 节逐项可指认：行情九件、实验六件、赛跑本体、安全两件、蜘蛛本体与工具清单。
6. 全部新代码过语法校验（py_compile / node --check），本地全路由 200 后才许推送；推送后 GitHub 回读哈希一致。
